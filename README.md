# payday2-mod-menu
Brandon’s Stealth Menu puts you in control of PAYDAY 2. Press F5 to adjust damage, speed, stealth, equipment and timers. Customize the artwork and controls with any color, save favorites or enjoy rainbow cycling. Save gameplay presets and make each heist your own. Host-only features require solo or hosting.

You need SuperBLT and BeardLib. Carry Stacker Reloaded is optional for carrying multiple bags. Skip dependencies you already installed.
1. Close PAYDAY 2. Open your game folder:
   D:\SteamLibrary\steamapps\common\PAYDAY 2


2. Install SuperBLT. Follow the official installation page: install its linked Microsoft Visual C++ runtime, then download the current 64-bit loader. Extract its DLL into the game folder beside PAYDAY2.exe. Launch the game and select Yes when it offers to download the base mod. Close the game afterward.


3. Install BeardLib. Download BeardLib, extract it, and place the BeardLib folder inside PAYDAY 2\mods. Check that this file exists:
   PAYDAY 2\mods\BeardLib\mod.txt


4. Optional: install Carry Stacker. Download the mod ZIP from Carry Stacker Reloaded releases. Extract its mod folder into PAYDAY 2\mods. Its mod.txt should be directly inside that folder.


5. Install Brandon’s menu [ file name HeistAssist ] . Download the menu ZIP Create a folder named HeistAssist inside mods, then extract the ZIP’s contents into it. Choose Replace files when updating your existing copy.
